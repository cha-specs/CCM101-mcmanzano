# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's public cloud computing platform. Azure provides cloud services for computing, storage, networking, databases, security, artificial intelligence, analytics, and application development.

Azure is widely used by organizations that already depend on Microsoft technologies.

## Global Infrastructure

Azure operates a global infrastructure consisting of regions and other geographic locations. This infrastructure allows organizations to deploy applications closer to their users and support availability, performance, compliance, and data residency requirements.

## Cloud Management Console

The **Azure Portal** is a web-based management interface for Microsoft Azure. It allows users to create, configure, monitor, and manage Azure resources.

Through the Azure Portal, users can manage virtual machines, storage accounts, virtual networks, databases, identities, and many other services.

## Four Core Services

| Service | Category | Purpose |
|---|---|---|
| Azure Virtual Machines | Compute | Provides scalable virtual machines for Windows and Linux workloads. |
| Azure Blob Storage | Storage | Stores unstructured data such as documents, images, videos, and backups. |
| Azure Virtual Network | Networking | Provides private networking and network communication between Azure resources. |
| Microsoft Entra ID | Identity | Manages user identities and controls access to applications and resources. |

## Three Advantages

### 1. Microsoft Integration

Azure integrates strongly with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, .NET, and other Microsoft products.

### 2. Enterprise Features

Azure provides services for enterprise security, governance, compliance, hybrid cloud, and identity management.

### 3. Global Infrastructure

Azure has a large global infrastructure that supports organizations with international users and applications.

## Typical Enterprise Use Cases

Azure can be used for:

- Windows Server migration
- Hybrid cloud environments
- Microsoft 365 integration
- Enterprise applications
- Virtual desktop infrastructure
- Database hosting
- Web application hosting
- AI and machine learning
- Disaster recovery
