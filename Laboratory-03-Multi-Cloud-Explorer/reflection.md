# Mission Reflection

This laboratory activity helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. It requires understanding the organization's requirements and comparing the capabilities of different providers. Through my research on AWS, Microsoft Azure, and Google Cloud, I learned that the three platforms offer similar basic services such as computing, storage, networking, databases, identity management, and Kubernetes.

I learned that AWS has a very broad range of services and is suitable for many different types of organizations. Microsoft Azure is particularly useful for organizations that already use Microsoft products such as Windows Server, Microsoft 365, and Active Directory. Google Cloud is a strong option for organizations focused on Artificial Intelligence, Machine Learning, data analytics, and Kubernetes.

The client recommendation activity helped me understand how technical decisions can be connected to business requirements. For example, I recommended Azure for the university because it already uses Microsoft technologies. For the AI research company, I selected Google Cloud because of its strong AI/ML services and Kubernetes capabilities. For the startup and global e-commerce company, AWS was a suitable option because of its broad services and scalability.

The Linux investigation also improved my technical skills. I used commands such as `cat`, `lscpu`, `free`, and `df` to examine the operating system, CPU, memory, and disk space of the KillerCoda environment. This showed me that understanding the existing server is important before deciding how it should be migrated to the cloud.

Another important skill I developed was technical documentation. Organizing my work into different Markdown files made the information easier to understand and review. Using GitHub also helped me improve my portfolio because I can now show my cloud research, comparisons, recommendations, and Linux investigation in one organized project.

Overall, this mission helped me understand the role of a cloud engineer and taught me that cloud decisions should be based on both technical capabilities and actual business needs.
