# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's public cloud computing platform.

Google Cloud provides services for computing, storage, networking, databases, security, data analytics, artificial intelligence, machine learning, and containers.

## Global Infrastructure

Google Cloud provides infrastructure through global regions and zones. Regions represent geographic locations, while zones are separate deployment areas within regions.

This infrastructure allows organizations to deploy applications closer to their customers and design systems that can provide high availability.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to manage Google Cloud resources and projects.

Users can create and manage virtual machines, storage, networks, databases, Kubernetes clusters, identities, and other cloud resources.

## Four Core Services

| Service | Category | Purpose |
|---|---|---|
| Compute Engine | Compute | Provides configurable virtual machines for cloud workloads. |
| Cloud Storage | Storage | Provides scalable object storage for files and application data. |
| Virtual Private Cloud (VPC) | Networking | Provides virtual networking for Google Cloud resources. |
| Cloud IAM | Identity | Controls access to Google Cloud resources using identities and roles. |

## Three Advantages

### 1. Artificial Intelligence and Machine Learning

Google Cloud provides strong AI and machine learning services and infrastructure for organizations developing intelligent applications.

### 2. Kubernetes

Google Cloud provides **Google Kubernetes Engine (GKE)**, a managed Kubernetes service for deploying and managing containerized applications.

### 3. Data Analytics

Google Cloud provides powerful data and analytics services that can help organizations process and analyze large amounts of information.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Artificial intelligence
- Machine learning
- Data analytics
- Kubernetes applications
- Containerized applications
- Global web applications
- Data warehousing
- Application development
- API hosting
