# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a public cloud computing platform launched in 2006. AWS provides a broad range of services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

AWS allows organizations to obtain computing resources and services through the internet without having to purchase and maintain all physical infrastructure themselves.

## Global Infrastructure

AWS organizes its infrastructure into geographic **Regions** and **Availability Zones**. A Region represents a separate geographic area, while Availability Zones are isolated locations within a Region.

Using multiple Availability Zones can help organizations design applications with higher availability and fault tolerance.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and manage cloud resources through the console.

The console provides access to services such as EC2, S3, VPC, IAM, databases, monitoring tools, and many other AWS services.

## Four Core Services

| Service | Category | Purpose |
|---|---|---|
| Amazon EC2 | Compute | Provides virtual servers that can run applications and operating systems. |
| Amazon S3 | Storage | Stores objects such as files, backups, images, videos, and application data. |
| Amazon VPC | Networking | Provides an isolated virtual network for AWS resources. |
| AWS IAM | Identity | Controls user identities, roles, permissions, and access to AWS resources. |

## Three Advantages

### 1. Broad Service Selection

AWS provides a large variety of cloud services covering computing, storage, networking, databases, security, analytics, AI, and more.

### 2. Global Infrastructure

AWS has a large global infrastructure that allows organizations to deploy applications in different geographic regions.

### 3. Scalability

AWS resources can be increased or decreased depending on workload requirements. This makes AWS suitable for applications that experience changing levels of traffic.

## Typical Enterprise Use Cases

AWS can be used for:

- Web application hosting
- Mobile application backends
- E-commerce systems
- Data backup
- Disaster recovery
- Enterprise databases
- Artificial intelligence and machine learning
- Data analytics
- Global applications
- Cloud-native applications
