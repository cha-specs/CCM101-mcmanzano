# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I believe compute resources are one of the most important components of cloud infrastructure because they provide the processing power required to run applications and services. Without compute resources, applications would not be able to process requests, perform calculations, or serve users. However, I also learned that compute cannot work effectively by itself because it depends on storage, networking, memory, and the operating system.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, flexible, and powerful operating system for servers. Through the Linux terminal, administrators can monitor system resources, configure services, manage files, troubleshoot problems, and automate tasks. My experience with KillerCoda helped me understand how Linux commands can be used to investigate a cloud server.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, resources, configurations, and decisions that will be used. Proper documentation can help engineers understand the environment, reduce mistakes, troubleshoot problems, and maintain the infrastructure more efficiently. It also makes it easier for team members to understand the system.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using commands such as `lscpu`, `free`, `df`, `findmnt`, `hostname`, and `hostname -I`. I also improved my understanding of compute, storage, networking, and operating system resources. Additionally, I learned how to compare equivalent services between AWS, Azure, and Google Cloud.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and professional because I added a complete laboratory folder containing technical reports, cloud documentation, provider comparisons, screenshots, and a reflection. This activity also improved my understanding of using GitHub as a portfolio for documenting technical projects and demonstrating my cloud computing skills.

## Conclusion

Overall, this laboratory gave me practical experience in investigating cloud infrastructure and documenting technical findings. It helped me connect theoretical cloud computing concepts with an actual Linux environment and gave me a better understanding of the responsibilities of a cloud engineer.
