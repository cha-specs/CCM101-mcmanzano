# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the basic infrastructure components that support cloud computing. Using the KillerCoda Linux Playground, I investigated a cloud-based Linux environment and identified its compute, storage, networking, and operating system resources.

The activity also involved researching the services provided by Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Their equivalent infrastructure services were compared to understand how different cloud providers implement similar cloud computing concepts.

Finally, I created a simple cloud infrastructure diagram and documented my findings using Markdown files in my GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

The major infrastructure components investigated in this laboratory are:

### Compute

Compute resources provide the processing power required to execute applications, services, and workloads. In the KillerCoda environment, the CPU and available processing cores represent the compute resources.

### Storage

Storage resources provide space for operating system files, applications, configurations, and user data. The Linux file system and available disk capacity represent storage resources in the laboratory environment.

### Networking

Networking allows computers, servers, applications, and users to communicate with one another. The KillerCoda environment provides networking resources such as an IP address, network interfaces, and connectivity to the Internet.

### Operating System

The operating system manages the server's hardware and provides the environment where applications and services can run. In this laboratory, the Linux operating system manages the compute, memory, storage, and networking resources.

## Linux Commands Executed

The following Linux commands were used during the investigation:

```bash
cat /etc/os-release
uname -r
lscpu
nproc
free -h
df -h
findmnt
hostname
hostname -I
```

These commands were used to identify the operating system, kernel, CPU, CPU cores, RAM, disk capacity, mounted file systems, hostname, and IP address.
