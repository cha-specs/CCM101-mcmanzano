# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on understanding cloud storage and deploying an object storage server using MinIO. The activity demonstrates how different types of cloud storage work and how object storage can be used to manage user-uploaded files such as images.

## Objectives

- Understand the three primary types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy a MinIO object storage server using Docker.
- Access the MinIO Web Console.
- Create a storage bucket and upload a sample file.
- Document the deployment process and reflect on the activity.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Linux Command Line
- Web Browser

## Skills Learned

- Understanding different cloud storage types
- Deploying services using Docker
- Using Linux command-line commands
- Configuring ports and environment variables
- Creating and managing object storage buckets
- Uploading files to MinIO
- Documenting cloud infrastructure tasks
